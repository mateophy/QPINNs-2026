## 🌟 Descripción

Este repositorio contiene la investigación y desarrollo de **Redes Neuronales Informadas por Física Cuántica (QPINNs)**, una innovadora fusión entre:

- 🧠 **Redes Neuronales Artificiales**
- ⚛️ **Computación Cuántica**  
- 📐 **Physics-Informed Neural Networks (PINNs)**

Los QPINNs aprovechan principios de mecánica cuántica para resolver ecuaciones diferenciales complejas y modelar sistemas físicos con mayor precisión y eficiencia computacional.

## 🎯 Objetivos del Proyecto

### Objetivos Principales
- [ ] Desarrollar arquitecturas híbridas cuántico-clásicas para PINNs
- [ ] Implementar algoritmos cuánticos variacionales para resolver EDPs
- [ ] Optimizar la codificación de datos físicos en estados cuánticos
- [ ] Comparar rendimiento QPINNs vs PINNs clásicos

### Aplicaciones Target
- 🌊 **Dinámica de fluidos cuántica**
- ⚡ **Electromagnetismo cuántico**
- 🔬 **Mecánica cuántica molecular**
- 🌡️ **Transferencia de calor en sistemas cuánticos**

## 🛠️ Tecnologías y Dependencias

### Stack Tecnológico
- **🐍 Python 3.8+** - Lenguaje principal
- **🔥 PyTorch/TensorFlow** - Framework de deep learning
- **⚛️ Qiskit/PennyLane** - Computación cuántica
- **🔢 NumPy/SciPy** - Computación científica
- **📊 Matplotlib/Plotly** - Visualización

### Instalación
```bash
# Clonar el repositorio
git clone https://github.com/alcidesmontoyac/QPINNs-2025.git
cd QPINNs-2025

# Crear entorno virtual
python -m venv qpinns_env
source qpinns_env/bin/activate  # Linux/Mac
# qpinns_env\Scripts\activate  # Windows

# Instalar dependencias
pip install -r requirements.txt
```
